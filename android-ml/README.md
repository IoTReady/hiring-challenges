> This is an advanced challenge that will potentially need a full day for completion unless you are already familiar with Firebase ML.
> This challenge is meant for intern Android developers. 

0. Build an app that uses [OCR](https://en.wikipedia.org/wiki/Optical_character_recognition) to recognise the weight from [this image](media/scale_ocr.jpg).
1. Use on phone recognition via [Firebase ML](https://firebase.google.com/products/ml) - no calls to Google Vision APIs allowed.
2. Use [Jetpack Compose](https://developer.android.com/compose) - assignments using XML layouts will not be reviewed.
2. As a bonus, implement the ability to focus only on 7 segment LED displays so that other numbers in the image are ignored.
3. Build the code and submit a video APK and Github repo. Also explain any specific issues you faced and debugged.
4. Submit your work to [work@iotready.co](mailto:work@iotready.co)
